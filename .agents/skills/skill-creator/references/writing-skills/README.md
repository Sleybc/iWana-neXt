# Guía de redacción de skills (migrada de writing-skills)

Material de apoyo de `skill-creator`. Se carga solo cuando hace falta; las reglas del catálogo iWana (dónde se edita, formato de descripción, trazabilidad) están en `../../SKILL.md` y prevalecen sobre cualquier documento de esta carpeta.

| Necesidad | Lee |
| --- | --- |
| La skill no se encuentra o no dispara («SEO para LLMs») | [CSO](references/cso/README.md) |
| El agente ignora o racionaliza las reglas | [Anti-racionalización](references/anti-rationalization/README.md) |

Notas de migración: de `writing-skills` solo se conservan estos dos documentos. El resto (plantillas, estándares de frontmatter de OpenCode, niveles Tier 1-3, guía de pruebas y material de apoyo) se descartó; el nivel Tier 3 estaba pensado para AWS o Convex y la cita a `opencode-expert` apuntaba a una skill que no existe. Las rutas de ejemplo con `~/.config/opencode/skills/` son ilustrativas: en este repo las skills viven en `.agents/skills/`.
